MESAI PWA v2.0.0 — Ali Erkonak

Bu paket Scriptable veya Kestirmeler gerektirmeyen web uygulamasıdır.
Kayıtlar uygulamanın iPhone'daki yerel web depolamasında tutulur.

Dosyalar yedeği:
- Uygulamada “Yedek al”a dokun.
- iOS paylaşım ekranından “Dosyalara Kaydet”i seç.
- Önerilen klasör: iPhone’umda > Mesai

Excel:
- İstediğin döneme ‹ / › ile geç.
- “Excel”e dokun.
- Paylaşım ekranından “Dosyalara Kaydet”i seç.
- Dosya adı: Mesai_YYYY-AA-GG_YYYY-AA-GG.xlsx

Geri yükleme:
- “Yedekten yükle”ye dokun.
- Daha önce kaydettiğin Mesai_Yedek_*.json dosyasını seç.
- Eski Scriptable JSON yedekleri de desteklenir.

Ana ekrana eklemek için uygulamanın HTTPS üzerinden yayınlanması gerekir.
Safari’de yayınlanan adresi aç > Paylaş > Ana Ekrana Ekle > Web Uygulaması Olarak Aç.

Hesap kontrol örneği:
08:30–21:00 hafta içi = 12,5 brüt − 8 normal − 1 yemek − 1 ekstra = 2,5 saat net.
